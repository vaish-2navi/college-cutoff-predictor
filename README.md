# 🎓 College Cutoff Predictor

An AI/ML-powered web application that predicts college admission cutoffs based on university, academic year, category, seat type, and cutoff figure type.

## 🚀 Live Demo

**Try the application here:** [College Cutoff Predictor](https://college-cutoff-predictor.streamlit.app/)

## 📌 Project Overview

Choosing the right college can be challenging for students during the admission process. The College Cutoff Predictor aims to help students estimate college admission cutoffs using a trained Machine Learning model.

Users can select their preferred university and admission details to obtain a predicted cutoff from the trained model.

## ✨ Features

- 🎯 Predict college cutoffs using Machine Learning.
- 🏛️ Select a university using its university ID.
- 📅 Choose the admission year.
- 👥 Select an admission category.
- 🎓 Choose the seat type.
- 📊 Select the cutoff figure type.
- ⚡ Interactive web interface built with Streamlit.
- 🤖 Uses a trained Random Forest regression model.

## 🧠 Machine Learning Model

The project uses a trained Scikit-learn Pipeline containing:

- **Preprocessor:** `ColumnTransformer`
- **Categorical encoding:** `OneHotEncoder`
- **Prediction algorithm:** `RandomForestRegressor`

### Input Features

1. `university_id`
2. `year`
3. `category`
4. `seat_type`
5. `figure_kind`

The model processes the selected inputs and returns a predicted cutoff.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/college-cutoff-predictor.git
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Navigate to the project directory

```bash
cd college-cutoff-predictor
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 6. Run the application

```bash
python -m streamlit run app.py
```

The application will open in your browser, usually at `http://localhost:8501`.

## ⚠️ Disclaimer

Predicted cutoffs are estimates generated by a Machine Learning model. Actual admission cutoffs may vary depending on official admission rules, seat availability, applicant performance, category, and yearly trends. Always verify admission decisions using official university or counselling authority information.
